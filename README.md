> 以音乐为桥，连接京滇山海。

十四个日夜，我们走进澜沧江畔的校园与村寨，用歌声、琴声和真诚的陪伴记录相遇，也记录音乐连接彼此的时光。

## 导语

2026 年盛夏，北科大“酉良和音滇韵民族团结实践团”的 7 名成员跨越千里，来到云南省澜沧拉祜族自治县。十四个日夜里，我们走进校园与村寨，用歌声、琴声和真诚的陪伴记录相遇，也记录音乐连接彼此的时光。

## 这个项目是什么

“和音滇韵”是本次音乐支教与民族团结实践的成果展示网页，也是团队为这段经历留下的一份数字记忆。网页整理了实践期间的文字记录、团队故事和现场影像，希望让更多人了解这次实践，感受音乐连接不同地域与不同成长经历的力量。

**在线访问**：https://finderlzy.github.io/DianRhyme/

## 实践内容

### 音乐支教

团队走进当地学校开展音乐课程，通过歌唱、器乐和音乐欣赏等内容，与同学们一起学习、练习和表演。音乐课堂不仅传授知识，也成为孩子们表达自己、认识彼此的空间。

### 交流与走访

实践团通过校园交流、村寨走访和文化体验，了解澜沧当地的自然环境、民族文化与生活故事，在真实的接触中感受不同地域之间的联系。

### 实践记录

网站按日期整理实践日志，记录音乐课堂、交流走访和团队生活中的片段；“精彩瞬间”则以可交互的照片空间呈现旅途影像。你可以拖动页面旋转照片宇宙、使用滚轮缩放，并点击照片查看对应的时间、地点与故事。

## 我们想留下的

这不是一份简单的行程汇报，而是一段关于相遇、陪伴与共同成长的记录。

音乐让陌生的面孔拥有共同的节拍，也让相隔千里的青春在澜沧江畔彼此回应。愿每一次歌唱都能种下理解与友谊，愿这段滇行记忆继续回响。

## 技术栈

网站使用 [Astro](https://astro.build/) 构建，结合 TypeScript、Three.js 与原生 CSS，实现静态页面、响应式布局和照片空间的交互体验。
